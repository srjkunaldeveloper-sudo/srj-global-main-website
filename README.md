# SRJ Global Company Website

This repository contains the completely redesigned and upgraded website for SRJ Global. 

## 🚀 Recent Updates
- **UI/UX Redesign:** A modern, beautiful, and dynamic frontend to provide an excellent user experience.
- **Backend Integration:** Added a fully functional backend system to handle dynamic data, forms, and admin functionalities.
- **Database:** Included a SQL database structure for managing company data securely.

## 📂 Project Structure
- `frontend/`: Contains the modern UI code built with React/Vite.
- `backend/`: Contains the server-side logic and API endpoints.
- `srj_db_backup.sql`: The database schema and backup required to run the backend locally.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, CSS (Modern Web Technologies)
- **Backend:** Node.js / Express (or corresponding backend technology)
- **Database:** SQL

## ⚙️ How to Run Locally

### Frontend
1. Navigate to the frontend directory: `cd frontend`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

### Backend
1. Navigate to the backend directory: `cd backend`
2. Install dependencies: `npm install`
3. Setup your `.env` variables for the database connection.
4. Run the server: `npm start` (or `npm run dev`)

### Database
- Import the provided `srj_db_backup.sql` file into your local SQL database server (e.g., MySQL or PostgreSQL).
